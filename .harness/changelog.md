    - 퍼실리테이터 검색 지원: 테이블(찹츄, 카피바라, 스카이), 회의실(몽키, 워터, 포그), 좌석(스턴/c1r1s9/c1r9s1) 양방향 실시간 검색 매칭 및 정밀 포커스, 시설 클릭 시 모달 내 '퍼실리테이터 공용 공간' 및 상주자 표기.
    - 모바일 스크롤 인디케이터 개선: C1 구역 끝 도달 시 왼쪽 버튼, C2 구역 끝 도달 시 오른쪽 버튼 노출을 차단하여 불필요한 화살표 제거, 스크롤 정지 1.2초 후 자동 숨김 처리 및 180도 회전 시 스크롤 방향 보정.
  - `src/App.css`: 3층 전용 레거시 스타일(.restricted-l-content 등) 완전 제거.
- **사유:** 사용 불가 층 UI/데이터 정리, 신규 퍼실리테이터 배치 반영 및 모바일 뷰포트 내 불필요한 인디케이터 노출 방지를 통한 사용성 개선.
- **검증 결과:** `npm run lint` 0 errors / 0 warnings 통과, `npm run build` Vite 번들 생성 성공.
